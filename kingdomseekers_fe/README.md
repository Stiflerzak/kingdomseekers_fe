# Kingdom Seekers Eastern Bypass — digital concept

An exploratory Next.js prototype for the Nairobi Eastern Bypass branch. The public site introduces the church; `/member` demonstrates a mobile-first companion for discipleship and community. All forms and member actions are local demonstrations. No account, database, payment, livestream, or messaging integration exists yet.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Run `npm run build` for a static production build in `out/`.

## What is in the prototype

- Public home: welcome, branch story, first-visit flow, ministry tabs, discipleship, media concept, location and FAQs.
- Member preview: devotional completion and saving, sample course progress, group interest, event interest, mobile navigation.
- SEO foundation: semantic sections, descriptive metadata, responsive layout. Crawling is intentionally disabled until real branch content and the final domain are approved.
- Hero image: generated **concept image**, not documentary photography of Kingdom Seekers. Replace with licensed, approved branch media before launch.

## Content truth

The user supplied the Eastern Bypass branch, Rev. Simon Chege and the relationship to Apostle Kimani. Public results support the wider Kingdom Seekers presence in Nakuru and identify Apostle John Kimani William. A [2023 sermon on Rev. Simon Mwangi Chege's YouTube channel](https://www.youtube.com/watch?v=-otUcXwUwrw) names Kingdom Seekers Fellowship Utawala; a [Nairobi listing](https://www.bizlaza.com/KE/Nairobi/1477002-2/genre/184266718279692/Christian%2BChurches) names an Eastern Bypass branch. These do not establish an approved brand, current address, service times, contact details or schedule. The prototype avoids inventing them.
